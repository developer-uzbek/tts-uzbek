🎙️ Uzbekcha TTS — Qo'llanma & API Hujjatlari

Uzbekcha TTS — matnni tabiiy o'zbek nutqiga (MP3) aylantiruvchi bepul va ommaviy platforma.

1. Tezkor Havola (GET)

Matndan to'g'ridan-to'g'ri MP3 olish:

GET https://tts-uzbek.onrender.com/tts.mp3?q=Salom%20dunyo&voice=sardor

2. REST API (POST)

curl -X POST https://tts-uzbek.onrender.com/api/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"Salom, dunyo!","voice":"uz-UZ-SardorNeural"}' \
  -o audio.mp3
